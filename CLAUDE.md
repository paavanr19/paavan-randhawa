## Architecture

Single-page portfolio rendered via **TanStack Start** (SSR framework on top of TanStack Router + Vite). The entry points are:

- `src/start.ts` — creates the TanStack Start instance with CSRF and error middleware
- `src/router.tsx` — creates the router with `routeTree.gen.ts` (auto-generated, do not edit manually)
- `src/routes/__root.tsx` — root shell: `<html>/<body>` wrapper, Vercel Analytics, global error boundary
- `src/routes/index.tsx` — the entire portfolio (one route, one component `Index`)

**`src/routes/index.tsx`** is the heart of the site. It owns:
- The `altTheme` (Halloween) toggle state — session-only, never persisted
- The cinematic intro lifecycle (`intro` state: `"playing" | "done"`)
- Scroll progress bar (via `progressRef` + `--scroll-y` CSS variable updated in the scroll listener)
- The typewriter greeting, project carousel, and contact form

**Content and data** live outside the route component:
- `src/lib/portfolio-content.json` — bio, projects, skills, interests text
- `src/lib/education.ts` — structured course list with SFU calendar links; edit here for course changes
- `src/lib/interests-assets.ts` — imports all interest photo `.asset.json` pointers; add new photos here

**Styling** is entirely in `src/styles.css` — Tailwind 4 with CSS custom properties. Theme tokens (`--background`, `--primary`, `--secondary`, etc.) are defined on `:root`; the Halloween alt-theme overrides them on `html.alt-theme`. No Tailwind utility classes for layout/typography — everything is hand-authored CSS classes (`.portfolio-nav`, `.portfolio-shell`, etc.).

**shadcn/ui** components are in `src/components/ui/` and use the `new-york` style. Add new ones with `npx shadcn@latest add <component>`.

## Key components

- `DraggableSticker` — portals to `document.body` via `createPortal` once dragged. Two placement modes:
  - `"doc"` (default): `position:absolute` with document-absolute coordinates (`rect + window.scrollX/Y`). Sticker scrolls with the page and stays where placed relative to content.
  - `"fixed"`: `position:fixed` with viewport coordinates. Used when the sticker is dropped onto the sticky navbar (detected via cursor position against `.portfolio-nav` rect — use cursor, not sticker top-left, because the sticker top can be above the navbar rect while the cursor is clearly on it).
  - All drag deltas are computed in document space so scrolling mid-drag doesn't shift the sticker.
  - When portaled, inline `bottom:"auto"` and `right:"auto"` cancel any conflicting CSS class properties (e.g. `.portrait-heart-wrap { bottom:12px; right:-18px }` would otherwise stretch the element).
  - CSS color rules for stickers must not require a parent selector (e.g. `.projects-star`, not `.section-heading .projects-star`) — the portaled element loses its original DOM ancestry.
- `CinematicIntro` — self-contained animated intro with deterministic scene timers; total runtime is 8500ms. Skip via Escape or click. Calls `onDone` when complete.
- `PixelSticker` — inline SVG pixel-art stickers using CSS custom property colors (`var(--foreground)`, `var(--secondary)`, etc.).

## Important constraints

- **Do not force-push or amend published commits** — this repo is connected to Lovable, which syncs from git history. Rewriting history breaks Lovable's project state.
- `vite.config.ts` delegates entirely to `@lovable.dev/vite-tanstack-config`. Do not add TanStack Router plugin, Vite React plugin, Tailwind plugin, or `tsConfigPaths` manually — they are already included and duplicates will break the build.
- `routeTree.gen.ts` is auto-generated by TanStack Router's Vite plugin on `npm run dev/build`. Never edit it.
- `src/styles.css` is the single source of truth for visual direction. Keep presentation styles here, not inline or in Tailwind utilities.
- Keep portrait content (projects, courses, resume) in the structured content files (`portfolio-content.json`, `education.ts`), not hardcoded in JSX.
